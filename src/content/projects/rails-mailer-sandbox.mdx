## The solution

Preview customer emails and attachments locally inside Rails without a separate email-testing service.

## What changed

Captures persistent MIME messages with searchable previews, attachment downloads, and sandboxed HTML rendering.

## Source

[Explore repository](https://github.com/azmi2409/rails-mailer-sandbox).

## AI system implementation

No AI runtime is involved. Action Mailer messages are captured as MIME files and rendered in a local inbox. Filesystem locking and atomic writes protect concurrent delivery; sandboxed HTML previews block scripts and remote resources. This is a deterministic development tool, not an AI email generator.
