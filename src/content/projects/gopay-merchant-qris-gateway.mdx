## The solution

Connect QRIS payment requests, payment matching, and order updates. Unofficial and not affiliated with or endorsed by GoPay.

## What changed

Combines dynamic QRIS payments, transaction matching, signed webhooks, and a separate administration service.

## Source

[Explore repository](https://github.com/azmi2409/gopay-merchant-qris-gateway).

This project uses unofficial private APIs. Accounts risk suspension; use official payment providers for critical production workloads.

## AI system implementation

No AI model participates in payment creation or settlement. TypeScript code generates QRIS payloads, matches transactions, and signs webhooks; SQLite tracks state and prevents duplicate claims. The SvelteKit admin service stays separate from the gateway. Payment decisions rely on validated amounts and transaction records, not probabilistic model output.
