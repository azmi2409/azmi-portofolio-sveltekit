## The solution

Keep listing metadata in frontmatter and long-form writing in MDX. Shared Svelte layouts provide the presentation, while content files own the case studies and articles.

## What changed

The site now compiles local blog and project files with mdsvex, validates metadata, and loads article components by route. Stable slugs preserve existing links. Project and blog pages have no runtime CMS dependency.

## Technical decisions

- Keep content trusted and version-controlled; compile it during the application build.
- Use server loaders for metadata and route-split components for article bodies.
- Use Motion’s small native-animation API for entrances and CSS for portrait depth.
- Respect reduced-motion preferences and preserve readable server-rendered content without JavaScript.

## Lessons learned

A portfolio should make content easy to keep useful. For a developer-maintained site, local files provide a straightforward review and publishing workflow.
