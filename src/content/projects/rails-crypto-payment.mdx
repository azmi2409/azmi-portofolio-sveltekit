## The solution

Convert Rupiah prices into exact USDT amounts with BigDecimal, reserve unique six-decimal amounts, and retrieve deposits from EVM chains or exchange internal transfers.

## Implementation

EVM JSON-RPC filters ERC-20 Transfer logs by token and recipient, verifies successful transaction receipts, and converts amounts using token decimals. Oversized RPC block ranges split on range errors. Binance and Bybit clients sign requests with host-provided credentials; Bybit deposit retrieval paginates results.

## Payment boundaries

The host application owns credentials, wallets, payment records, polling cursors, expiration, settlement, transaction locking, and jobs. Database uniqueness must protect reservations atomically. Deposit status, coin, amount, recipient, and timestamps must match before transactional settlement.

## AI system implementation

No AI runtime is involved. BigDecimal arithmetic, validated RPC responses, and signed exchange requests keep payment matching deterministic. Model output never determines amounts or settlement.
