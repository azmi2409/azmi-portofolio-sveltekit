## The solution

[KilatBot](https://kilatbot.com), also known as [KilatHost](https://kilat.host), is a managed service for AI agents shaped to a business. An owner starts from a template — Social Media Planner, Operations Reporter, General Assistant, or Coder — and can change the agent's role, skills, schedules, and tools later. Chat happens in the browser or on Telegram. Pictures, files, and voice notes can be sent from the browser. The service is operated by PT Kilat Inovasi Cerdas, an Indonesian PT Perseorangan based in Bogor.

## What changed

kilatbot.com and kilat.host now present KilatBot, not a one-click host whose homepage offered Hermes Agent and n8n deployment. Agents remember the work, run on a schedule, and ask before risky actions. The terms of service, effective 18 October 2026, still describe the agents as built on the open-source Hermes Agent by Nous Research, keep PocketBase backends for existing customers, and keep existing n8n services running. n8n is closed to new deployments.

## Behind the solution

Agents start on Kilat AI, KilatBot's own model service, so a separate API key is not required at the start. An owner can add a provider key in the agent's settings instead. A connected assistant can use the workspace through the MCP endpoint at https://kilat.host/mcp. Risky commands, purchases, and making a shared page public ask first. The live browser can be watched and taken over for a sign-in or a payment.

Azmi Muwahid founded KilatBot in 2026 and leads its development. KilatBot's about page also says he wrote the open-source QRIS and USDT payment libraries the platform uses.

### Key features

- Templates for reports, content, and everyday help. Coder needs Plus or higher and builds and publishes sites.
- Browser chat, plus Telegram, with memory and schedules between chats.
- A live browser the owner can watch and take over.
- Kilat AI included with the plan, or a provider key the owner adds.
- The homepage invites people to join the waitlist. The pricing page says payments are not open yet.

### Constraints

- There is no self-hosted edition.
- Agents need a plan. Business is US$9 a month, or US$86 a year (save 20%), with 3 agents and up to 5 people. The FAQ last checked 13 November 2026 said payments were not open yet, and that invited people can use a code for Business free for a set time.
- Agents sleep when idle. The service is best effort and does not promise an uptime guarantee.
- KilatBot is not affiliated with CloudKilat or PT Infinys System Indonesia.
